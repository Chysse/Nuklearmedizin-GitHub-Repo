## Der Fall

Eine ältere Dame (72 Jahre) hat seit vielen Jahren Gelenkschmerzen und rheumatische Beschwerden. Durch den Flyer einer Klinik ist sie auf die Radon-Therapie aufmerksam geworden. Ihre Kinder fragen euch um Rat.

## So funktioniert die Waage

Bei einer **Bewertung** legt ihr Argumente wie Gewichte auf zwei Waagschalen: links, was *für* die Therapie spricht, rechts, was *dagegen* spricht. Jedes Argument bekommt Punkte – je wichtiger, desto mehr. Am Ende zeigt die Waage eine Richtung, aber die Entscheidung trefft ihr: Ihr müsst begründen, warum die Punkte so verteilt sind.

Wichtig ist die Trennung von **Sachaussagen** („Radon-222 ist ein Alphastrahler mit 3,8 Tagen Halbwertszeit“ – prüfbar, mit Quelle) und **Werturteilen** („Ein kleines Krebsrisiko ist für eine 72-Jährige mit starken Schmerzen vertretbar“ – eine Abwägung, über die man verschiedener Meinung sein kann). Beides gehört in die Bewertung, aber getrennt gekennzeichnet.

## Aufgaben

**Aufgabe 1 – Austausch.** Tauscht euch zunächst über die Ergebnisse der Expertengruppen aus. Informiert euch gegenseitig über die Radon-Therapie und ihre Anwendungsgebiete sowie über die Problematik von Radon in Innenräumen und mögliche Schutzmaßnahmen. Jede Person notiert drei Sätze zur *anderen* Seite.

**Aufgabe 2 – Kriterien sammeln.** Überlegt in der Gruppe je **drei mögliche Vorteile** der Radon-Therapie und **drei mögliche Nachteile oder Risiken** und tragt sie in die Tabelle ein. Markiert jedes Kriterium mit **S** (Sachaussage, mit Quelle) oder **W** (Werturteil).

| | | | | | |
| | | | | | |
| | | | | | |
| | | | | | |
| **Summe** | | | **Summe** | | |

**Aufgabe 3 – Punkte.** Bewertet jedes Kriterium auf einer Skala von **1 (kaum wichtig) bis 5 (sehr wichtig)** und begründet jede Punktzahl in einem Satz. Denkt daran: Es geht um *diese* Patientin – Alter, Beschwerden, Alternativen.

**Aufgabe 4 – Entscheidung.** Addiert die Punkte. Überwiegen die Vorteile oder die Nachteile? Würdet ihr als Sohn oder Tochter der Dame zu einer Therapie raten? Notiert einen kurzen Text – und nennt die Bedingung, unter der ihr anders entscheiden würdet (z. B. „wenn sie Raucherin ist“, „wenn die Schmerzmittel gut wirken“, „wenn sie im Keller eines Granithauses wohnt“).

**Aufgabe 5 – Der Sportler.** Überlegt, ob ihr auch einem 24-jährigen Sportler, der sich beim Training schwer verletzt hat, zu einer Radon-Behandlung raten würdet. Welche Punkte in der Tabelle ändern sich, welche nicht? Begründet.

!!! tipp "Argumente aus der Physik"
    Argumente, die ihr belegen könnt: Alphastrahlung wirkt nur im Körper (Reichweite) · Dosis der Kur ≈ 1–2 mSv, verglichen mit 2,1 mSv natürlicher Belastung pro Jahr · kurzlebige Zerfallsprodukte setzen sich in der Lunge fest · Radon-222 mit 3,8 Tagen Halbwertszeit ist nach der Kur schnell weg · das Risiko durch Strahlung summiert sich über das Leben (Alter!) · Rauchen und Radon verstärken sich.
