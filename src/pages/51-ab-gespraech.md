## Teil 1 · Ihr seid Ärztin oder Arzt (euer Verfahren)

Bereitet euch in eurer Pfad-Gruppe auf ein Gespräch mit einer Patientin oder einem Patienten vor. Nutzt eure Patienteninformation aus Modul II. Notiert zu jeder Leitfrage konkrete Stichpunkte – mit Zahlen.

| Leitfrage | Eure Stichpunkte |
| --- | --- |
| Welche fachlichen Inhalte sind für das Verfahren wichtig? (Nuklid, Strahlungsart, Halbwertszeit, Ablauf) | |
| Über welche Risiken müsst ihr aufklären? (Dosis mit Vergleich, Nebenwirkungen) | |
| Welche Fragen könnte die Patientin stellen? (mindestens fünf, mit Antwort) | |
| Wie bereitet ihr die Patientin auf das Verfahren vor? (Was passiert wann? Was muss sie mitbringen, beachten?) | |
| Wie könnt ihr Ängste nehmen – ohne zu verharmlosen? (ehrliche Vergleiche, Schutzregeln mit Begründung, Nutzen) | |

**Gesprächsaufbau (Vorschlag):** Begrüßung und Anlass → „Was wissen Sie schon?“ → Ablauf in drei Sätzen → Warum Strahlung, warum dieses Nuklid → Wie viel Strahlung, verglichen mit … → Verhaltensregeln danach (mit Zeitangaben) → „Welche Fragen haben Sie noch?“ → Abschluss.

!!! tipp "Fachwörter übersetzen"
    Schreibt für die drei wichtigsten Fachwörter eures Verfahrens je eine Alltagsübersetzung auf: *Halbwertszeit* → „Nach … Stunden ist nur noch die Hälfte da.“ · *Gammastrahlung* → … · *effektive Dosis* → …

## Teil 2 · Ihr seid Patientin oder Patient (das andere Verfahren)

Nun nehmt ihr die Rolle einer Person ein, bei der das **andere** Verfahren durchgeführt werden soll (Pfad A: Radioiodtherapie · Pfad B: Szintigraphie). Sammelt Fragen, die ihr einer Ärztin oder einem Arzt stellen würdet – mindestens sechs, darunter mindestens zwei, die schwer zu beantworten sind. Ideen: Was passiert genau? Tut es weh? Wie lange bin ich radioaktiv? Darf mein Kind auf den Schoß? Darf meine schwangere Tochter kommen? Was passiert, wenn ich Nein sage? Wie viel ist das im Vergleich zum Fliegen? Bleibt etwas für immer im Körper?
