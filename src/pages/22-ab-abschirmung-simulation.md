Mit einer realitätsnahen **GeoGebra-Simulation** untersuchst du, wie gut Blei (und Eisen) Gammastrahlung abschirmen. Die Simulation zeigt die Zählrate eines γ-Strahlers, der durch eine oder mehrere Platten abgeschirmt wird; Anzahl und Dicke der Platten kannst du verändern.

!!! info "Die Simulationen"
    - Abschirmung durch **Blei**: [geogebra.org/m/kz97spk2](https://www.geogebra.org/m/kz97spk2)
    - Abschirmung durch **Eisen**: [geogebra.org/m/mffspduv](https://www.geogebra.org/m/mffspduv)

![Bildschirmfoto der GeoGebra-Simulation: Strahler, Bleiplatten, Zählrohr, Schieberegler für N und d](assets/geogebra_abschirmung.jpg "Die Simulation: Strahler links, Platten in der Mitte, Zählrohr rechts")

**Bedienung:** Kontrollkästchen *Strahler* – Strahler hinzufügen oder wegnehmen · Schieberegler *N* – Anzahl der Platten · Schieberegler *d* – Dicke jeder Platte · die aktuelle **Zählrate** wird angezeigt.

## Aufgaben

**Aufgabe 1 – Nullrate.** Das Zählrohr wird nicht nur von der Strahlung des Präparats getroffen, sondern auch von der Umgebungsstrahlung. Ermittle zuerst die Nullrate $R_0$ (Zählrate ohne Strahler; mehrfach messen und mitteln). Der Abstand Zählrohr–Präparat lässt sich in der Simulation nicht verändern – auch im echten Versuch **muss** er konstant bleiben. Begründe diese Maßnahme.

**Aufgabe 2 – Messreihe.** Bestimme die Zählrate in Abhängigkeit von der gesamten Schichtdicke $d$, die sich aus den hintereinander gestellten Bleiplatten ergibt. Berücksichtige die Nullrate.

| Schichtdicke $d$ in cm | 0 | | | | | | | | |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| Zählrate $R$ in 1/s | | | | | | | | | |
| Netto-Zählrate $R - R_0$ in 1/s | | | | | | | | | |

**Aufgabe 3 – Diagramm.** Erstelle aus den Messwerten ein Diagramm (x-Achse: Schichtdicke, y-Achse: Netto-Zählrate) und zeichne von Hand eine Ausgleichskurve ein. Beschreibe den Verlauf des Graphen.

**Aufgabe 4 – Halbwertsdicke.**

!!! info "Info"
    Die **Halbwertsdicke** $d_{1/2}$ eines Materials gibt an, bei welcher Dicke sich die Zählrate infolge der Abschirmung auf den halben Wert reduziert. Sie hängt vom Material **und** von der Energie der Strahlung ab.

Untersuche, ob es sinnvoll ist, bei diesem Versuch den Begriff *Halbwertsdicke* zu verwenden (halbiert sich die Zählrate immer wieder nach derselben zusätzlichen Dicke?). Erläutere, wie du vorgegangen bist. Wenn ja: Bestimme die Halbwertsdicke von Blei in diesem Versuch.

**Aufgabe 5 – Eisen.** Untersuche mit der zweiten Simulation, ob es auch für Eisen sinnvoll ist, eine Halbwertsdicke anzugeben, und bestimme sie gegebenenfalls.

**Aufgabe 6 – Anwendung.**

1. Welches Material ist zur Abschirmung besser geeignet – Eisen oder Blei? Begründe.
2. Bestimme die Dicke einer Bleischicht, die mindestens 90 % der einfallenden Strahlung abschirmt.

**Aufgabe 7 – Die Bleischürze.** Die Abschirmfähigkeit von Blei hängt stark von der Energie der Strahlung ab. Röntgenstrahlung, wie sie beim Zahnarzt verwendet wird, ist deutlich energieärmer als γ-Strahlung.

1. Für typische Röntgenstrahlung beträgt die Halbwertsdicke von Blei nur $d_{1/2} \approx 0{,}2\ \mathrm{mm}$. Bleischürzen haben eine Bleischicht von höchstens $0{,}5\ \mathrm{mm}$. Beurteile die Schutzwirkung dieser Schürzen beim Röntgen.
2. Beurteile die Schutzwirkung derselben Schürze bei γ-Strahlung (Halbwertsdicke aus Aufgabe 4). Wie viele Schürzen müsste man übereinander tragen, um γ-Strahlung auf 50 % zu reduzieren? Was lässt sich über die Schutzwirkung bei Alpha- und Betastrahlung sagen?
